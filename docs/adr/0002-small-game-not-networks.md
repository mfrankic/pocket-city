# Small game, not a utility network

The game we are finishing is roads, zones, buildings, money, demand, population, and jobs. A city can stagnate or go broke (cannot spend); it cannot lose. We are not building power, water, traffic, services, pollution, or individual agents. Those turn a watchable loop into an unfinished Cities: Skylines. Add a system only when the small game is already fun and that system changes a decision the player makes.
