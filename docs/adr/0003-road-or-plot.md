# A lot is a road or a plot

Each lot is either a Road or a Plot, not an exclusive soup of terrain/zone/building flags. Plots keep their zone when a building is demolished, so zoning is a decision and buildings can come and go. Roads cannot be zoned. Stamping a facility on a zoned plot clears the zone, so a Station is not also Residential. We rejected a single exclusive state machine because it forces the player to re-paint zone after every demolish. Revisited against the originating ChatGPT share: still no Small/Large roads; a lot is not road-plus-zone.
