# Uncovered fire decays slowly; Firehouse is still the recover action

Fire without Firehouse coverage used to sit at full intensity forever, so a broke city could not recover. Uncovered lots now decay at half the Firehouse rate; a Month still leaves fire burning. Firehouse coverage still decays faster and still blocks ignition. We rejected stamping a Firehouse into the tiny opener as the only fix: that would hide the loop instead of making recover possible.
